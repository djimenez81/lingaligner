# lingaligner documentation

- [Project summary](summary.md) — what the package is, its status, its
  roadmap, and how it relates to the published study.
- [Concepts](concepts.md) — the mental model: items, costs, the two
  views of one number, alignments, corpora, and the two distance
  modes.
- [Tutorial](tutorial.md) — a worked example, from two forms to a
  matrix.
- [API reference](api.md) — the public classes and functions.
- [Design notes](design.md) — why the layers are where they are.
- [Decisions](decisions.md) — the dated decision log with the costs of
  each choice.

If you are new to `lingaligner`, read the summary first, then the
concepts, then the tutorial. The API reference is for lookup, not for
learning.

If you arrived from the published Chibchan study, read the
"Reproducing the original study" section of **Design notes** before
comparing numbers: four conventions differ, deliberately, and the
section says which.
